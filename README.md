E-Commerce Sales & Funnel Analysis Project

Project Overview

This project is an end-to-end data analytics solution built using SQL Server and Power BI.
It analyzes user behavior on an e-commerce platform using a real-world dataset sourced from Kaggle.

The project focuses on understanding customer journey, sales performance, conversion funnel, and revenue insights.

 Problem Statement

Despite high user traffic and platform activity, the business faces challenges such as:

Low conversion rate from product views to purchases
Lack of visibility into customer drop-off points in the funnel
No clear understanding of top-performing products and brands
Unstructured reporting system for decision-making
Limited insights into revenue contribution by category and brand

This project aims to solve these problems using data-driven analysis.

Source: Kaggle E-commerce Dataset
Contains user-level event data: views, cart additions, purchases
Fields include: user_id, product_id, brand, category, price, event_type, event_time

Project Workflow
1. Data Import
Raw dataset imported into SQL Server (SSMS)

2. Data Cleaning & Validation
Handled missing values (brand, category)
Removed duplicate records using ROW_NUMBER()
Ensured data consistency and accuracy
   
3.Exploratory Data Analysis (SQL)
Event distribution analysis
Revenue calculation
User and session analysis
Product and brand performance

4.KPI Development
Total Revenue
Total Users
Total Sessions
Total Purchases
Average Order Value
Conversion Rate
 
5.Funnel Analysis
View → Cart → Purchase flow analysis
Drop-off identification
Conversion rate calculation
 
6.Time Series Analysis
Monthly revenue trends
Monthly purchase trends
User activity trends
 
7.Dashboard Creation (Power BI)
Interactive dashboard with KPIs and visuals
Funnel chart, bar charts, and line graphs
Executive summary and trend analysis pages

Key Insights
Identified top revenue-generating brands and categories
Found major drop-off points in customer journey
Analyzed monthly growth trends in revenue and users
Measured overall conversion rate across the funnel
Highlighted most active users and high-value customers
